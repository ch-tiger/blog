#git #自定义域名

配置git

1、创建 git 仓库

2、绑定自定义域名（使用 custom.com）

如果您希望使用第三方购买的域名（如 example.com），而非 github.io 域名：

  1. 购买域名：在域名注册商（如腾讯云、阿里云等）购买自己的域名。
  2. 配置 DNS 解析：
    • 在注册商处将域名通过 CNAME 记录指向 username.github.io，或者使用 A 记录指向 GitHub 的 IP 地址（185.199.108.153 等）。
  3. 配置 GitHub Pages：
    • 进入您的 GitHub 仓库，点击 Settings。
    • 在左侧导航栏，点击 Pages。
    • 在 Custom domain 中输入您的自定义域名，点击 Save。
  4. 验证：页面上方会显示“Enforce HTTPS”，勾选以确保安全。
