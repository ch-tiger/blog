torch_npu 适配深度分析

torch_npu 通过插件机制将华为昇腾 NPU 无缝接入原生 PyTorch，其核心思路是：利用 PyTorch 预留的 PrivateUse1 后端扩展点。以下是完整适配链路：

一、架构总览

PyTorch 原生                           torch_npu 插件
┌─────────────────────┐     ┌──────────────────────────────────────┐
│  torch.Tensor       │ ──▶ │  生成 .npu() 方法                    │
│  torch.nn.Module    │ ──▶ │  生成 .npu() 方法                    │
│  torch.Storage      │ ──▶ │  生成 .npu() 方法                    │
│  DeviceType::CUDA   │     │  DeviceType::PrivateUse1 → "npu"     │
│  DispatchKey::CUDA  │ ──▶ │  DispatchKey::PrivateUse1            │
│  CUDAGuardImpl      │ ──▶ │  NPUGuardImpl (C10_REGISTER)         │
│  c10::Stream        │ ──▶ │  NPUStream                           │
│  torch._C           │ ──▶ │  torch_npu._C (pybind扩展)           │
│  torch.backends     │ ──▶ │  entry_points: torch.backends        │
│  torch.cuda.*       │ ──▶ │  torch.npu.* (镜像API)               │
│  torch.distributed  │ ──▶ │  HCCL backend (替代NCCL)             │
│  torch.compile      │ ──▶ │  NPU Inductor backend                │
│  torch.autograd     │ ──▶ │  autograd 算子注册                   │
│  CANN               │     │  (CANN/ACL底层计算库)                 │
└─────────────────────┘     └──────────────────────────────────────┘
