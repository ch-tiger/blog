最合理的组合做法（业界实践）：

第 1 步：方案 A 冒烟
  → 100 条 prompt，token 匹配率 > 0.85 → 继续往下
  → 否则直接 C 定位

第 2 步：方案 B 验收
  → MMLU / GSM8K / HumanEval 各跑一遍
  → acc 差 < 1% → 精度等价，可上线
  → acc 差 > 2% → 回到第 3 步

第 3 步：方案 C 定位（仅当 B 不达标）
  → 逐算子对比，找到第一个超阈值的算子
  → 针对该算子修复（换实现 / 调精度模式）

对你的场景（H20 vs NPU，SGLang），最合理的方案：

主用 lm_eval 做精度验收，msprobe 做根因定位，自定义输出比对只做冒烟。

具体优先级：

  1. 先用方案 A 100 条 prompt 快速冒烟（半小时）
  2. 通过后用方案 B lm_eval 跑 MMLU+GSM8K+HumanEval 验收（几小时）
  3. B 不达标时，用方案 C msprobe 逐算子定位（按需）
# H20 侧
lm_eval --model sglang \
    --model_args base_url=http://h20-host:30000,model=meta-llama/Meta-Llama-3-8B-Instruct \
    --tasks gsm8k,mmlu,humaneval \
    --num_fewshot 0 \
    --batch_size 8 \
    --output_path results_h20/

# NPU 侧（同样命令，只换 base_url）
lm_eval --model sglang \
    --model_args base_url=http://npu-host:30000,model=meta-llama/Meta-Llama-3-8B-Instruct \
    --tasks gsm8k,mmlu,humaneval \
    --num_fewshot 0 \
    --batch_size 8 \
    --output_path results_npu/

关键约束：

  • --num_fewshot 两边必须一致
  • lm_eval 的 sglang 模型类已内置，直接用 --model sglang
  • 同一份 --tasks，别加随机子集

msprobe 本身设计目标是"NPU 对标其他框架"（如 PyTorch / MindSpore），典型用法：

pip install msprobe
# 1. H20 侧 dump 基准 tensor
from msprobe.pytorch import PrecisionDebugger
# 在 H20 的 forward 里 hook 关键算子，dump 输入输出

# 2. NPU 侧 dump 对应 tensor
from msprobe.mindspore import PrecisionDebugger  # 或 ascend 后端
# 同样 hook 同名算子

# 3. 比对
msprobe --compare h20_dump/ npu_dump/ \
    --output_path compare_result/

它生成的报告类似：

Layer                  max_diff    rmse    cosine    status
layers.0.self_attn     0.012       0.003   0.9998    PASS
layers.0.mlp           0.234       0.089   0.9871    FAIL  ← 这里发散
layers.1.self_attn     0.045       0.012   0.9989    PASS
...

难点：

  • H20 侧走 PyTorch / SGLang，NPU 侧走 torch_npu 或 MindSpore，算子命名要对齐（SGLang 的 LlamaAttention 在 MindSpore 里可能叫别的）
  • 需要在两边的 forward 里插入相同位置的 hook
  • msprobe 主推 MindSpore ↔ PyTorch 比对，SGLang（PyTorch 生态）对比 NPU 时，本质是 PyTorch CUDA vs torch_npu，可以用它的 PyTorch 模式 dump H20，再用 ascend 模式 dump NPU

python -m sglang.launch_server \

    --seed 42 \

关键点：
`--seed 42` 固定随机数，配合 `temperature=0` 保证完全可复现。
- **采样参数固定**：`temperature=0`（贪心解码），`top_p=1.0`，确保可复现
- **固定 random seed**：通过请求中的 `seed` 字段或服务端 `--seed`
- **相同输入**：保存 prompt 列表到文件，所有平台用同一份

新建脚本 gen_outputs.py


import json, requests, os

SERVER_URL = "http://localhost:30000"
PROMPT_FILE = "prompts.jsonl"
OUTPUT_FILE = os.environ.get("OUTPUT_FILE", "outputs_baseline.jsonl")
MODEL_NAME  = os.environ.get("MODEL_NAME", "llama-3-8b")

def generate(text: str):
    """贪心解码，完全确定性。"""
    resp = requests.post(
        f"{SERVER_URL}/generate",
        json={
            "text": text,
            "sampling_params": {
                "max_new_tokens": 256,
                "temperature": 0,   # 贪心，可复现
                "top_p": 1.0,
                "top_k": -1,
            },
            "stream": False,
        },
        timeout=300,
    )
    resp.raise_for_status()
    out = resp.json()
    return out["text"], out.get("output_ids", [])

def main():
    with open(PROMPT_FILE, "r", encoding="utf-8") as f:
        prompts = [json.loads(line) for line in f if line.strip()]

    results = []
    for i, p in enumerate(prompts):
        text, ids = generate(p["text"])
        rec = {
            "id": i,
            "prompt": p["text"],
            "output_text": text,
            "output_ids": ids,
        }
        results.append(rec)
        print(f"[{i+1}/{len(prompts)}] done, tokens={len(ids)}")

    with open(OUTPUT_FILE, "w", encoding="utf-8") as f:
        for r in results:
            f.write(json.dumps(r, ensure_ascii=False) + "\n")
    print(f"Saved {len(results)} outputs to {OUTPUT_FILE}")

if __name__ == "__main__":
    main()

新建 compare_outputs.py：

import json, argparse, difflib

def load(path):
    with open(path, "r", encoding="utf-8") as f:
        return [json.loads(l) for l in f if l.strip()]

def token_match_rate(ids_a, ids_b):
    """Token 序列匹配率（短边对齐）。"""
    n = min(len(ids_a), len(ids_b))
    if n == 0:
        return 0.0, 0
    hit = sum(1 for i in range(n) if ids_a[i] == ids_b[i])
    return hit / n, n

def text_similarity(a, b):
    """字符级相似度 (0~1)。"""
    sm = difflib.SequenceMatcher(None, a, b)
    return sm.ratio()

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--baseline", required=True)
    ap.add_argument("--target",   required=True)
    ap.add_argument("--out", default="compare_report.json")
    args = ap.parse_args()

    base = load(args.baseline)
    tgt  = load(args.target)
    assert len(base) == len(tgt), f"数量不一致: {len(base)} vs {len(tgt)}"

    rows = []
    for a, b in zip(base, tgt):
        assert a["id"] == b["id"], f"id 不匹配: {a['id']} vs {b['id']}"
        tm, n = token_match_rate(a["output_ids"], b["output_ids"])
        ts = text_similarity(a["output_text"], b["output_text"])
        rows.append({
            "id": a["id"],
            "len_base": len(a["output_ids"]),
            "len_target": len(b["output_ids"]),
            "token_match_rate": round(tm, 4),
            "text_similarity": round(ts, 4),
        })

    avg_tm = sum(r["token_match_rate"] for r in rows) / len(rows)
    avg_ts = sum(r["text_similarity"]  for r in rows) / len(rows)
    print(f"\n=== Summary ({len(rows)} samples) ===")
    print(f"平均 token 匹配率 : {avg_tm:.4f}")
    print(f"平均文本相似度    : {avg_ts:.4f}")

    # 列出差异最大的样本
    worst = sorted(rows, key=lambda r: r["text_similarity"])[:5]
    print("\n差异最大的 5 个样本:")
    for r in worst:
        print(f"  id={r['id']:>3}  tok_match={r['token_match_rate']:.3f}  text_sim={r['text_similarity']:.3f}")

    with open(args.out, "w", encoding="utf-8") as f:
        json.dump({"summary": {"avg_token_match_rate": avg_tm,
                                "avg_text_similarity": avg_ts},
                    "rows": rows}, f, ensure_ascii=False, indent=2)
    print(f"\n详细报告已写入 {args.out}")

if __name__ == "__main__":
    main()
