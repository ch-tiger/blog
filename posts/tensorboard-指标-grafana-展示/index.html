问题一

如果写一个 exporter, 用来解析 tensorboard 生成的 metrics文件在暴露给 Prometheus，不做侵入式修改，功能是否可行且一样？

可行，而且是一个很好的“零侵入”方案，但功能不完全一样。更准确地说：

TensorBoard event exporter 能把“已经写入 TensorBoard 的指标”暴露给 Prometheus；直接在训练进程里加 Prometheus metrics 能暴露“训练运行时现场所有你想拿的指标”。

可行性 Megatron-LM 已经在 training_log() 里大量写 TensorBoard scalar，入口在 training.py：

if writer and (iteration % args.tensorboard_log_interval == 0):
    writer.add_scalar('learning-rate', learning_rate, iteration)
    writer.add_scalar('batch-size', batch_size, iteration)
    writer.add_scalar(key, loss_dict[key], iteration)
    writer.add_scalar('loss-scale', loss_scale, iteration)
    writer.add_scalar('grad-norm', grad_norm, iteration)
    ...

所以你完全可以写一个独立 exporter：

  1. 训练进程正常启用 TensorBoard：
    --tensorboard-dir /path/to/tensorboard_logs
--tensorboard-log-interval 1
--log-timers-to-tensorboard
--log-throughput
  2. exporter 进程读取 /path/to/tensorboard_logs/events.out.tfevents.*
  3. exporter 自己监听 :8080/metrics
  4. Prometheus scrape exporter
  5. Grafana 查 Prometheus

这个方案不需要改 Megatron-LM 源码，部署上也更舒服。

不完全等价的地方 不等价主要有 4 点：

  1. 指标覆盖范围受 TensorBoard 写入限制
    TensorBoard 没写的指标，exporter 就拿不到。比如 throughput 只有在 --log-throughput 且 --log-timers-to-tensorboard 时才会写入 TensorBoard，位置在 training.py。内存指标也要开 --log-memory-to-tensorboard。

  2. 有延迟
    TensorBoard SummaryWriter 有队列，默认 tensorboard_queue_size = 1000，见 training_config.py。event 文件落盘、exporter 读取、Prometheus scrape 都会带来延迟。训练内直接暴露 metrics 延迟更低。

  3. 指标语义会更像“日志回放”
    Prometheus 更偏当前状态和时间序列采样。TensorBoard event 是 append-only 日志，exporter 通常要维护“每个 tag 的最新 step/value”。可以展示曲线，但要小心 event 文件 rotation、断点续训、重复 step、多个 event 文件的问题。

  4. 多 job / 多 rank 标签要自己处理
    Megatron 的 TensorBoard writer 只在 rank == world_size - 1 创建，见 global_vars.py，这点反而是好事，不会多 rank 重复写。但 exporter 需要给指标补上 run/job/host/logdir 这类 label，否则 Grafana 上多个训练任务会混在一起。

推荐实现方式 我建议做独立 exporter，而且用它作为第一版。它满足“不侵入源码”，风险低，Prometheus/Grafana 链路能很快跑通。

技术选择：

pip install prometheus-client tensorboard

核心读取可以用 TensorBoard 的：

from tensorboard.backend.event_processing.event_accumulator import EventAccumulator

exporter 逻辑：

acc = EventAccumulator(logdir)
acc.Reload()

for tag in acc.Tags()["scalars"]:
    events = acc.Scalars(tag)
    latest = events[-1]
    gauge.labels(tag=sanitize(tag)).set(latest.value)

Prometheus metric 可以设计成一个通用指标：

megatron_tensorboard_scalar{tag="learning_rate", run="gpt_7b"} 0.00012
megatron_tensorboard_scalar_step{tag="learning_rate", run="gpt_7b"} 1200
megatron_tensorboard_scalar_wall_time{tag="learning_rate", run="gpt_7b"} 1780936712

也可以把常用 tag 映射成更漂亮的独立指标：

megatron_train_learning_rate
megatron_train_loss
megatron_train_throughput_tflops_per_gpu

第一版我会选“通用 scalar + tag label”，省事、覆盖全、对 Megatron tag 变化更稳。

Grafana 查询示例

结论 可行，适合作为非侵入式方案；功能接近，但不完全一样。只要你接受“只能暴露 TensorBoard 已写入的指标”和“有几秒到几十秒延迟”，这个方案非常实际。要做到和训练内置 Prometheus 完全一致，则需要确保所有关心的指标都写入 TensorBoard，并处理好 event 文件 reload、重复 step、多个 run 的 label。

问题二

分析Megatron源码，如何添加metrics, 通过暴露8080端口，将训练指标暴露给 Prometheus， 将指标展示在grafana？

结论是：Megatron-LM 训练指标最合适的 Prometheus 接入点在 megatron/training/training.py 的 training_log()，因为这里已经集中拿到了 loss、learning rate、loss scale、grad norm、吞吐、memory、iteration、consumed samples 等训练态指标。HTTP exporter 建议在 megatron/training/global_vars.py 的 set_global_variables() 初始化阶段启动，且只在 args.rank == args.world_size - 1 这个现有 logging rank 上启动，避免多进程训练时所有 rank 都抢 8080 端口。

5. 新增内置 Prometheus helper prometheus_metrics.py

新建文件：megatron/training/prometheus_metrics.py

# Copyright (c) 2026, NVIDIA CORPORATION. All rights reserved.

"""Prometheus metrics helpers for Megatron training."""

import math
import re

_SERVER_STARTED = False
_PROMETHEUS_AVAILABLE = True

try:
    from prometheus_client import Gauge, start_http_server
except ModuleNotFoundError:
    _PROMETHEUS_AVAILABLE = False


def _make_gauge(*args, **kwargs):
    if not _PROMETHEUS_AVAILABLE:
        return None
    return Gauge(*args, **kwargs)


ITERATION = _make_gauge('megatron_train_iteration', 'Current training iteration.')
CONSUMED_SAMPLES = _make_gauge(
    'megatron_train_consumed_samples', 'Consumed training samples.'
)
LEARNING_RATE = _make_gauge('megatron_train_learning_rate', 'Current learning rate.')
LOSS_SCALE = _make_gauge('megatron_train_loss_scale', 'Current loss scale.')
GLOBAL_BATCH_SIZE = _make_gauge('megatron_train_global_batch_size', 'Global batch size.')
THROUGHPUT = _make_gauge(
    'megatron_train_throughput_tflops_per_gpu', 'Training throughput in TFLOP/s/GPU.'
)
ITERATION_TIME = _make_gauge(
    'megatron_train_iteration_time_seconds', 'Elapsed seconds per training iteration.'
)
GRAD_NORM = _make_gauge('megatron_train_grad_norm', 'Gradient norm.')
PARAMS_NORM = _make_gauge('megatron_train_params_norm', 'Parameters norm.')
NUM_ZEROS_IN_GRAD = _make_gauge(
    'megatron_train_num_zeros_in_grad', 'Number of zeros in gradients.'
)
SKIPPED_ITERATIONS = _make_gauge(
    'megatron_train_skipped_iterations', 'Skipped iterations in the current log window.'
)
NAN_ITERATIONS = _make_gauge(
    'megatron_train_nan_iterations', 'NaN iterations in the current log window.'
)
LOSS = _make_gauge('megatron_train_loss', 'Training loss.', ['name'])


def start_prometheus_server(port):
    """Start the Prometheus HTTP exporter once in this process."""
    global _SERVER_STARTED

    if _SERVER_STARTED:
        return True
    if not _PROMETHEUS_AVAILABLE:
        return False

    start_http_server(port)
    _SERVER_STARTED = True
    return True


def update_training_metrics(
    *,
    iteration,
    consumed_samples,
    learning_rate,
    loss_scale,
    batch_size,
    throughput=None,
    iteration_time=None,
    grad_norm=None,
    params_norm=None,
    num_zeros_in_grad=None,
    skipped_iterations=None,
    nan_iterations=None,
    losses=None,
):
    """Publish the latest training values to Prometheus gauges."""
    if not _PROMETHEUS_AVAILABLE:
        return

    _set(ITERATION, iteration)
    _set(CONSUMED_SAMPLES, consumed_samples)
    _set(LEARNING_RATE, learning_rate)
    _set(LOSS_SCALE, loss_scale)
    _set(GLOBAL_BATCH_SIZE, batch_size)
    _set(THROUGHPUT, throughput)
    _set(ITERATION_TIME, iteration_time)
    _set(GRAD_NORM, grad_norm)
    _set(PARAMS_NORM, params_norm)
    _set(NUM_ZEROS_IN_GRAD, num_zeros_in_grad)
    _set(SKIPPED_ITERATIONS, skipped_iterations)
    _set(NAN_ITERATIONS, nan_iterations)

    for name, value in (losses or {}).items():
        if _is_finite(value):
            LOSS.labels(name=_sanitize_label_value(name)).set(float(value))


def _set(gauge, value):
    if gauge is not None and _is_finite(value):
        gauge.set(float(value))


def _is_finite(value):
    if value is None:
        return False
    try:
        return math.isfinite(float(value))
    except (TypeError, ValueError):
        return False


def _sanitize_label_value(value):
    return re.sub(r'[^a-zA-Z0-9_]', '_', str(value))

6. 新增 TensorBoard 非侵入式 exporter tensorboard_prometheus_exporter.py

新建文件：tools/tensorboard_prometheus_exporter.py

# Copyright (c) 2026, NVIDIA CORPORATION. All rights reserved.

"""Export TensorBoard scalar event data as Prometheus metrics."""

import argparse
import math
import re
import time
from pathlib import Path

SCALAR_VALUE = None
SCALAR_STEP = None
SCALAR_WALL_TIME = None
EXPORTER_LAST_RELOAD = None
EXPORTER_RELOAD_SUCCESS = None


def parse_args():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument(
        '--logdir',
        type=Path,
        required=True,
        help='TensorBoard log directory containing events.out.tfevents files.',
    )
    parser.add_argument(
        '--port',
        type=int,
        default=8080,
        help='Port for the Prometheus /metrics endpoint.',
    )
    parser.add_argument(
        '--host',
        type=str,
        default='0.0.0.0',
        help='Host interface for the Prometheus HTTP server.',
    )
    parser.add_argument(
        '--run-name',
        type=str,
        default=None,
        help='Prometheus run label. Defaults to the TensorBoard log directory name.',
    )
    parser.add_argument(
        '--poll-interval',
        type=float,
        default=15.0,
        help='Seconds between TensorBoard event reloads.',
    )
    return parser.parse_args()


def main():
    args = parse_args()
    run_name = _sanitize_label_value(args.run_name or args.logdir.name)
    event_accumulator_cls, start_http_server = _load_dependencies()

    start_http_server(args.port, addr=args.host)
    print(f'> exporting TensorBoard scalars from {args.logdir} on {args.host}:{args.port}')

    accumulator = event_accumulator_cls(str(args.logdir), size_guidance={'scalars': 0})
    while True:
        reload_events(accumulator, run_name)
        time.sleep(args.poll_interval)


def _load_dependencies():
    global EXPORTER_LAST_RELOAD
    global EXPORTER_RELOAD_SUCCESS
    global SCALAR_STEP
    global SCALAR_VALUE
    global SCALAR_WALL_TIME

    try:
        from prometheus_client import Gauge, start_http_server
        from tensorboard.backend.event_processing.event_accumulator import EventAccumulator
    except ModuleNotFoundError as exc:
        raise SystemExit(
            'Missing exporter dependency. Install prometheus-client and tensorboard, '
            'or run inside the Megatron-LM container with the appropriate uv groups.'
        ) from exc

    SCALAR_VALUE = Gauge(
        'megatron_tensorboard_scalar',
        'Latest TensorBoard scalar value.',
        ['run', 'tag'],
    )
    SCALAR_STEP = Gauge(
        'megatron_tensorboard_scalar_step',
        'Latest TensorBoard scalar step.',
        ['run', 'tag'],
    )
    SCALAR_WALL_TIME = Gauge(
        'megatron_tensorboard_scalar_wall_time_seconds',
        'Latest TensorBoard scalar wall time.',
        ['run', 'tag'],
    )
    EXPORTER_LAST_RELOAD = Gauge(
        'megatron_tensorboard_exporter_last_reload_time_seconds',
        'Unix time when the TensorBoard exporter last reloaded events.',
        ['run'],
    )
    EXPORTER_RELOAD_SUCCESS = Gauge(
        'megatron_tensorboard_exporter_reload_success',
        'Whether the last TensorBoard event reload succeeded.',
        ['run'],
    )

    return EventAccumulator, start_http_server


def reload_events(accumulator, run_name):
    try:
        accumulator.Reload()
        for tag in accumulator.Tags().get('scalars', []):
            events = accumulator.Scalars(tag)
            if not events:
                continue
            latest = events[-1]
            if not math.isfinite(float(latest.value)):
                continue
            safe_tag = _sanitize_label_value(tag)
            SCALAR_VALUE.labels(run=run_name, tag=safe_tag).set(float(latest.value))
            SCALAR_STEP.labels(run=run_name, tag=safe_tag).set(float(latest.step))
            SCALAR_WALL_TIME.labels(run=run_name, tag=safe_tag).set(float(latest.wall_time))
        EXPORTER_LAST_RELOAD.labels(run=run_name).set(time.time())
        EXPORTER_RELOAD_SUCCESS.labels(run=run_name).set(1)
    except Exception as exc:
        EXPORTER_RELOAD_SUCCESS.labels(run=run_name).set(0)
        print(f'WARNING: failed to reload TensorBoard events: {exc}', flush=True)


def _sanitize_label_value(value):
    return re.sub(r'[^a-zA-Z0-9_]', '_', str(value))


if __name__ == '__main__':
    main()

使用说明

内置方案启动训练时加：

--prometheus-metrics-port 8080 --log-throughput

Prometheus 抓取：

scrape_configs:
  - job_name: megatron-training
    static_configs:
      - targets: ["<训练节点IP>:8080"]

TensorBoard exporter 方案：

python tools/tensorboard_prometheus_exporter.py \
  --logdir /path/to/tensorboard_logs \
  --port 8080 \
  --run-name gpt_run

两种方案不要同时占用同一个 8080。内置方案更实时、指标更明确；TensorBoard exporter 非侵入，但只能暴露已经写入 TensorBoard event 文件的 scalar。
